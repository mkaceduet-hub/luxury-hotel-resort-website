# Aurelia Hotel & Resort Website

A responsive multi-page hotel and resort website concept built with HTML, CSS and vanilla JavaScript.

## Pages
- Home — `index.html`
- About Us — `about.html`
- Rooms & Suites — `rooms.html`
- Room Details — `room-details.html`
- Dining — `dining.html`
- Gallery — `gallery.html`
- Offers & Packages — `offers.html`
- Contact & Booking — `contact.html`

## Features
- Eight separate HTML pages with shared navigation and footer
- Responsive layouts for desktop, tablet and mobile
- Room cards, image gallery and sample booking enquiry form
- Mobile navigation and basic JavaScript form interaction
- SEO description metadata

## Technologies
HTML5 · CSS3 · Vanilla JavaScript

## Run locally
Open `index.html` in a browser. Internet access is required for Google Fonts and Unsplash images.

## Deployment
Enable GitHub Pages from **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

## Demo note
Aurelia, contact details, room rates and offers are fictional sample content for a portfolio demonstration. The enquiry form does not submit real bookings.
